MCP on Agent Bazaar

Status: not yet built here — tracked openly, not hidden.

What's here today

Agent Bazaar's own catalog is reachable as plain JSON via /discovery/search and /discovery/resources — any MCP server can wrap those as tools today. A first-party MCP server for Agent Bazaar itself (exposing search_resources, get_resource, get_pricing and similar tools directly) is on the roadmap, not yet shipped.

Use an MCP server today

Saylor Innovations runs a production MCP server over its own catalog of research, security and Solana-intelligence endpoints:

{
  "mcpServers": {
    "saylor-innovations": {
      "url": "https://saylorinnovations.com/mcp"
    }
  }
}

MCP tool directory (planned)

Once built, every listed MCP server and tool will get its own permanent page here — name, description, transport, input/output schema, pricing, and whether it settles over x402 — the same treatment resources already get at /resources/{slug}. Watch the GitHub repo or open an issue if you want to help build it.
