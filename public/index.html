Humans browse. Agents need structured discovery.

A marketplace built for people to scroll is not enough for software that has to find, evaluate, pay for, and call a resource on its own. Agent Bazaar is both: a browsable AI agent marketplace for humans, and a machine-readable agent discovery and agent-to-agent commerce layer underneath it. Every resource here — x402 APIs, MCP servers, datasets, and other agent infrastructure — carries the structured fields an autonomous agent needs to decide what to call, what it costs, and how to pay for it, without a human in the loop.

An Open Marketplace for an Open Agent Economy

Agent Bazaar is open source and permissionless: no centralized company gatekeeps whether your API, MCP tool, or agent service is discoverable by autonomous software. It fully mirrors Coinbase's public x402 Bazaar catalog, so if your agent already queries Coinbase's Bazaar, pointing it here costs nothing — same resources, same wire format, zero migration. On top of that: everything permissionless-listed here that KYC keeps off Coinbase's, no account required to list or discover, and it's MIT-licensed so anyone can self-host their own copy of this exact catalog. Wire-compatible, not a rival catalog to reconcile.

Beyond APIs: agent-payable tips with Propz

Not every agent payment is for an API call. Propz is a sibling Saylor Innovations product for the human side of the same rails: a non-custodial tip jar any creator, streamer or builder can drop onto a website or share as a link — no signup, no custody, value settles directly to their own Solana or Base wallet, minus a disclosed 0.08% fee.

It's relevant here because it's agent-readable by design: every Propz card publishes a deterministic JSON payment manifest — network, asset and recipient, machine-parseable, no screen-scraping — so an agent can tip a creator the same structured way it pays for a resource on this marketplace.
